# HyperFold Benchmark Results

Measurements of the [HyperFold](https://github.com/jjllzhang/hyperfold) multilinear polynomial commitment scheme (PCS) across all 144 bundled parameter configurations.

## Setup & Parameters

- **Hardware & Runtime**: AMD EPYC 9754, 503 GiB RAM, 32 physical cores pinned via CPU affinity (32 Rayon threads); optimized release build (`target-cpu=native`)
- **Field & Challenges**: Goldilocks base field (`2^64 - 2^32 + 1`) with cubic extension challenges, or M127 base field (`2^127 - 1`) with quadratic extension challenges
- **Hash / Transcript**: BLAKE3 Merkle hashing (with domain separation between leaf and internal-node hashes) and a versioned Fiat–Shamir transcript
- **Security Target**: 100-bit interactive IOP plus commitment-binding error budget under bundled parameter certificates (Fiat–Shamir, Merkle hashing, PRG, and zero-knowledge security are not formally certified)
- **Scheme Constants**:
  - `r` in `{2, 4, 8}`: folding arity per round.
  - `c` in `{2, 4}`: inverse code rate (code rate `1/c`, i.e., `1/2` or `1/4`).
  - `QA` / `RS`: base-code backends, using Quasi-Abelian (`QA`) codes or Reed–Solomon (`RS`) codes.
  - Local folding matrices: specialized `2×2`, `4×4`, and `8×8` linear circuits (`H_2`, `H_4`, `H_8`) corresponding to `r = 2, 4, 8`.

## Measurement Methodology

- **Sampling**: 1 per-process warmup followed by 3 measured samples; `Commit`, `Open`, and `Verify` timings are **arithmetic means**.
- **Timing Scope**: `Commit` measures polynomial commitment generation (excluding setup and input generation); `Open` measures evaluation proof generation including Fiat–Shamir transcript computation (excluding witness release, serialization, and memory cleanup); `Prover` is `Commit + Open` (mean) computed at full precision prior to rounding; `Verify` measures proof verification against the commitment.
- **Proof Size**: Reported in KiB (`1 KiB = 1024 bytes`) rounded to 3 decimal places; **includes** the commitment together with the evaluation proof.
- **Verification**: Every measured sample passed verification.

`k` denotes the number of multilinear variables (`2^k` base-field elements). Rows within each variant are ordered by `(r, c, k)`.
